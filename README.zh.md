# 快速复制

版本 **1.0.3**。[English](README.md) · [更新日志](CHANGELOG.md)（每节先英文再中文） · [性能测试](benchmark.md)

面向 Windows 10/11 的文件工具，用于复制、移动和删除大量文件。程序采用文件级并发队列，适合包含大量小文件的目录；同一磁盘分区内的移动优先使用文件系统重命名。

同一分区、机械盘上的 `node_modules`（4019 个文件、61 MiB、平均约 15.5 KiB），FastCopy 1.0.2、16 线程对照资源管理器粘贴 / 永久删除（[性能测试](benchmark.md)）：

| | 资源管理器 | FastCopy |
| --- | ---: | ---: |
| 复制（粘贴） | 11.47 s | **0.93 s（12 倍）** |
| 永久删除 | 2.02 s | **1.02 s（2 倍）** |

资源管理器粘贴按它所使用的 `IFileOperation` 计时（无界面）。单个大文件通常仍受磁盘和缓存限制，那种情况不保证更快。

## 安装

1. 把 `fastcopy.exe` 放到一个固定目录（不要放在“下载”或解压后会删掉的临时文件夹）。右键菜单会记下这个 EXE 的完整路径。
2. 启动 `fastcopy.exe`，窗口会打开参数设置。
3. 单击「注册」（当前用户，无需管理员）。

之后在资源管理器中：选中文件或文件夹时出现「快速复制」子菜单；文件夹空白处在已剪切/复制后出现「快速粘贴」和「取消剪切/复制」。Windows 11 可能把传统菜单放在「显示更多选项」里。以后若移动 EXE，先从原位置卸载菜单，再从新路径启动并重新注册。

## 选中文件 / 文件夹

对一个或多个文件、文件夹（可混选）点右键，命令在「**快速复制**」子菜单里。程序会读取资源管理器当前选中项，因此可以超过约 100 个顶层选中项。

- **快速剪切** — 把选中项放进本程序自己的剪贴板（不覆盖 Windows 文本剪贴板）。之后在文件夹空白处粘贴即为移动。
- **快速复制** — 同样放入本程序剪贴板，之后粘贴即为复制。
- **快速删除** — 按设置中保存的方式删除（默认回收站；永久删除会先确认）。
- **复制为符号链接** — 记下选中项，准备粘贴为符号链接。再到文件夹空白处粘贴。
- **复制为硬链接** — 记下选中项，准备粘贴为硬链接。再到文件夹空白处粘贴。
- **打开链接目标** — 仅在单独选中快捷方式（`.lnk`）、符号链接或目录联接时出现。在资源管理器中打开真实目标。
- **查看源路径** — 同样仅单选链接时出现。弹窗显示路径（链接则为真实目标），可复制、可在资源管理器中打开。
- **统计大小** — 扫描选中项，显示文件数、目录数和字节。
- **复制路径** — 把路径按每行一条写入 Windows 文本剪贴板。按住 Shift 则为相对公共父目录的路径。
- **批量改名** — 整个选中只开一个窗口。原/新文件名列表都可编辑（删行或调整原文件名顺序会去掉/重排文件并重算）。打开时按 Everything 分析：公共前缀/后缀保持字面量，中间变化部分为 `%1`（旧表达式里 `*` 也是捕获）。新表达式中 `%1` 为该捕获，`#` / `###` 为编号。勾选「忽略扩展名」时按主文件名重新分析。
- **参数设置** — 打开本程序设置（上方有分隔线）。

## 文件夹空白处

在文件夹里的空白处点右键。仅在已经「快速剪切」「快速复制」或链接复制之后才出现，普通粘贴或取消后会再隐藏。

- **快速粘贴** — 把本程序剪贴板里的内容贴进当前文件夹。复制或剪切会打开进度窗口。若刚才是链接复制，文案变为「粘贴为符号链接」/「粘贴为硬链接」，多于 1 项时为「粘贴(x个文件)为…」；链接粘贴在后台完成，不弹出进度窗口，成功也不弹右下角通知。失败则弹出窗口说明原因。按住 Shift 再点则保留待粘贴列表，可以再粘一次。剪切仍会清空，因为源已经不在了。
- **取消剪切/复制** — 清空待粘贴列表，不执行粘贴。

「粘贴为符号链接」为每个顶层项在目标处创建一个指向源路径的符号链接（目录使用目录符号链接；创建符号链接可能需要开发人员模式）。「粘贴为硬链接」对文件调用硬链接；对文件夹则重建目录树并对内部文件创建硬链接（须在同一卷）。若目标处已有同名文件/文件夹，则新链接自动命名为「原名 2」「原名 3」……，不覆盖已有项。

## 执行之后

直接打开程序（没有右键任务）时显示参数设置；底部「保存设置」和「关闭」始终完整显示。复制、移动、删除只显示进度窗口（扫描、速度、剩余时间、暂停/取消）。成功结束后窗口会关闭；若设置中开启了完成提示则会弹出系统通知。通知以本程序身份发送，不会闪出 PowerShell。有错误则保留进度窗口，可重试或导出列表。符号/硬链接粘贴成功不通知；失败则弹出窗口说明原因。

永久删除不会进入回收站，开始前会再确认（命令行可用 `--yes` 跳过）。取消复制时，尚未完成的新目标文件会被清理；覆盖已有文件时先写入临时文件再替换，原文件在替换完成前保持不变。

设置保存在 `%LOCALAPPDATA%\FastCopy\settings.json`。

## 注册与语言

若以前用管理员注册过全机菜单，可用「卸载全机菜单（需管理员）」清除。卸载也在设置页执行；注册或卸载完成后会自动刷新菜单状态。升级带来的新菜单项和图标会在下次启动时自动补上。

文件夹空白处的粘贴/取消会立即跟随界面语言。级联子菜单文案在切换语言时也会更新。

## 引擎与设置

- 设置页可切换中文 / English 界面（下拉选项固定显示 `中文` / `English`）。窗口标题栏显示版本号（如 `快速复制 1.0.3`）。
- 冲突时覆盖、跳过或自动重命名；可选在大小和修改时间相同时跳过。
- 复制文件夹时可按 ignore 文件（默认 `.gitignore`）跳过匹配项。
- 硬链接/符号链接/目录联接：忽略（默认）、跟随目标，或保留为链接。
- 复制 NTFS 稀疏文件时保留空洞，不把全 0 区间写成实数据。
- 复制完成后可校验文件长度；会保留修改时间、访问时间和基本属性。
- 大量小文件用并发 `ReadFile`/`WriteFile` 复制，并与目录扫描重叠；大于等于 64 MiB 的文件单独用 1 个线程，并尝试无缓冲 CopyFileEx。
- 被占用的文件自动跳过，结束时可重试或导出列表。
- 界面字号接近普通 WinForm（9pt）；打开窗口时显示在当前屏幕正中。

## 命令行

无界面复制、移动或删除：

```text
fastcopy.exe --copy 源 [源…] 目标文件夹 [--workers 线程数] [--ignore]
fastcopy.exe --move 源 [源…] 目标文件夹 [--workers 线程数] [--ignore]
fastcopy.exe --delete 路径 [路径…] [--permanent|--recycle-bin] [--yes] [--ignore]
```

| 参数 | 含义 |
| --- | --- |
| `--workers N` | 并发线程数（1–64） |
| `--ignore` | 按设置中的 ignore 文件名跳过匹配项（目前仅复制文件夹时生效） |
| `--permanent` / `--recycle-bin` | 删除方式（仅删除命令） |
| `--yes` | 跳过永久删除确认 |

退出码：`0` 成功，`1` 有跳过（冲突跳过或相同则跳过），`2` 有失败，`3` 取消，`64` 参数错误。

其它命令：

```text
fastcopy.exe --settings
fastcopy.exe --register-shell
fastcopy.exe --unregister-shell
```

`--settings` 打开参数设置窗口。`--register-shell` / `--unregister-shell` 为当前用户注册或卸载右键菜单。

## 构建

需要 Rust stable、Visual Studio C++ Build Tools/Windows SDK；打包还需 7-Zip：

```powershell
cargo test --release
cargo build --release
node pack.js
```

可执行文件位于 `target/release/fastcopy.exe`。`node pack.js` 会编译 Release 并生成 `release/fastcopy_1.0.3.7z`（版本号来自 `Cargo.toml`）。Release 构建使用 OpenGL（glow）、LTO 和符号剥离以控制体积。

## 性能说明

对照数字见本文开头。方法、环境和分轮耗时见 [benchmark.md](benchmark.md)。

- 大量小文件主要受磁盘随机读写、杀毒扫描和文件系统元数据操作限制，适当增加并发数通常有效。
- 复制对小文件使用并发 `ReadFile`/`WriteFile`，并与目录扫描重叠。大于等于 64 MiB 的文件单独用 1 个线程，并尝试无缓冲 `CopyFileEx`（不被支持时回退）。
- 机械硬盘不宜设置过高并发，建议 2–4；SSD/NVMe 可从默认值开始测试。
- 回收站操作由 Windows Shell 完成，进度会在每个顶层项目完成后更新。

## 当前限制

- 首版仅支持 Windows 10/11 x64。
- ignore 文件仅在复制文件夹时生效，复制单个文件或移动/删除时不使用。
- 硬链接/符号链接/目录联接默认忽略；跟随则复制目标内容；保留则重建链接（目录联接会建成 junction；创建符号链接可能需要开发人员模式）。
- 文件校验目前校验长度，不计算内容哈希。
- 不复制 NTFS ACL 和备用数据流。目标卷不支持稀疏文件时会写成普通文件。
- 正在使用或共享锁定的文件会自动跳过，出现在结束时的失败列表中，可重试。其他权限或安全软件导致的失败也在同一列表中。
