# 快速复制

版本 **1.0.1**。[English](README.md) · [更新日志](CHANGELOG.md)

面向 Windows 10/11 的 Rust 文件工具，用于复制、移动和删除大量文件。程序采用文件级并发队列，适合包含大量小文件的目录；同一磁盘分区内的移动优先使用文件系统重命名。

## 功能

- 文件和文件夹复制、移动、删除
- 直接打开程序即显示参数设置；右键菜单任务只显示进度
- 设置页可切换中文 / English 界面（下拉选项固定显示 `中文` / `English`）
- 窗口标题栏显示版本号（如 `快速复制 1.0.1`）
- 复制/移动/删除开始前显示扫描进度
- 通过资源管理器右键菜单选择文件与目标
- 复制 NTFS 稀疏文件时保留空洞，不把全 0 区间写成实数据
- 总字节、文件数、当前文件、速度、每秒文件数、耗时和预计剩余时间
- 暂停、继续、取消，以及失败列表、重试和导出
- 冲突时覆盖、跳过或自动重命名；可选在大小和修改时间相同时跳过
- 复制文件夹时可按 ignore 文件（默认 `.gitignore`）跳过匹配项
- 硬链接/符号链接/目录联接：忽略（默认）、跟随目标，或保留为链接
- 默认移入回收站，可选择永久删除
- 复制完成后可校验文件长度；CopyFileEx 会保留修改时间、访问时间和基本属性
- 大于等于 64 MiB 的文件单独用 1 个线程，并尝试无缓冲 CopyFileEx
- 被占用的文件自动跳过，结束时可重试或导出列表
- 当前用户资源管理器级联菜单（无需管理员）：快速剪切、快速复制、快速删除、复制为符号链接/硬链接、打开链接目标、查看源路径、参数设置
- 已剪切、复制或链接复制后，文件夹空白处才出现「快速粘贴」（或「粘贴为符号链接/硬链接」）和「取消剪切/复制」
- 右键操作读取资源管理器当前选中项，可超过约 100 个顶层选中项
- 程序图标与右键菜单图标（剪切、复制、粘贴、删除）
- 界面字号接近普通 WinForm（9pt）
- 打开窗口时显示在当前屏幕正中
- 任务完成时可弹出系统通知（设置中可关；符号/硬链接粘贴单独一项）。通知以本程序身份发送，不会闪出 PowerShell 窗口；成功时进度窗口仍会自动关闭

## 使用

1. 直接打开程序时，窗口立即显示参数设置；底部「保存设置」和「关闭」始终完整显示。
2. 在资源管理器中选中文件或文件夹，用「快速复制」级联菜单执行剪切、复制或删除，或「复制为符号链接」「复制为硬链接」，也可「打开链接目标」、「查看源路径」或打开「参数设置」。若已剪切、复制或链接复制，在文件夹空白处可点「快速粘贴」（或「粘贴为符号链接/硬链接」），或「取消剪切/复制」清空待粘贴列表。
3. 粘贴或删除开始后，程序只显示进度窗口（速度、剩余时间、暂停/取消）。
4. 任务成功结束后窗口会自动关闭；若设置中开启了完成提示则会弹出系统通知。若有错误则保留进度窗口，可重试失败项或导出列表。

永久删除不会进入回收站，程序会在开始前再次确认（命令行可用 `--yes` 跳过）。取消复制时，尚未完成的新目标文件会被清理；覆盖已有文件时先写入临时文件再替换，原文件在替换完成前保持不变。

设置保存在 `%LOCALAPPDATA%\FastCopy\settings.json`。

## 右键菜单

在“参数设置”中单击“注册”，为当前 Windows 用户添加菜单（无需管理员）。若以前用管理员注册过全机菜单，可用“卸载全机菜单（需管理员）”清除。选中文件和/或文件夹（含多选、混选）时出现剪切、复制、删除、两项链接命令、「打开链接目标」、「查看源路径」和「参数设置」。点「打开链接目标」会在资源管理器中打开/选中符号链接、目录联接或快捷方式的真实目标。点「查看源路径」会弹出窗口显示路径（链接则为真实目标），可复制到剪贴板或在资源管理器中打开。选中文件或文件夹时没有「快速粘贴」；仅在已剪切、复制或链接复制后，文件夹空白处才显示粘贴和「取消剪切/复制」。链接复制后的粘贴文案为「粘贴为符号链接」/「粘贴为硬链接」，多于 1 项时为「粘贴(x个文件)为符号链接/硬链接」。Windows 11 可能把传统菜单显示在“显示更多选项”中。已注册的旧菜单会在下次启动时自动补上文件上的剪切/复制/删除。

“快速复制”“快速剪切”和链接复制使用程序自己的剪贴板，不会覆盖 Windows 文本剪贴板。执行粘贴后会清空这份剪贴板，需要再次剪切或复制才能粘贴。右键菜单会读取资源管理器当前选中项，因此可以超过约 100 个顶层选中项。快速删除采用设置中保存的默认删除方式。

「粘贴为符号链接」为每个顶层项在目标处创建一个指向源路径的符号链接（目录使用目录符号链接；创建符号链接可能需要开发人员模式）。「粘贴为硬链接」对文件调用硬链接；对文件夹则重建目录树并对内部文件创建硬链接（须在同一卷）。若目标处已有同名文件/文件夹，则新链接自动命名为「原名 2」「原名 3」……，不覆盖已有项。粘贴链接在后台完成，不弹出进度窗口。

卸载菜单可在设置页执行；注册或卸载完成后会自动刷新菜单状态。移动 EXE 后，需要从原位置卸载菜单并在新位置重新注册。更新图标或升级后也需要重新注册右键菜单。

文件夹空白处的粘贴/取消会立即跟随界面语言。级联子菜单文案在切换语言时也会更新。

## 命令行

无界面复制、移动或删除：

```text
fastcopy.exe --copy 源 [源…] 目标文件夹 [--workers 线程数] [--ignore]
fastcopy.exe --move 源 [源…] 目标文件夹 [--workers 线程数] [--ignore]
fastcopy.exe --delete 路径 [路径…] [--permanent|--recycle-bin] [--yes] [--ignore]
```

| 参数 | 含义 |
| --- | --- |
| `--workers N` | 并发线程数（1–64） |
| `--ignore` | 按设置中的 ignore 文件名跳过匹配项（目前仅复制文件夹时生效） |
| `--permanent` / `--recycle-bin` | 删除方式（仅删除命令） |
| `--yes` | 跳过永久删除确认 |

退出码：`0` 成功，`1` 有跳过（冲突跳过或相同则跳过），`2` 有失败，`3` 取消，`64` 参数错误。

其它命令：

```text
fastcopy.exe --settings
fastcopy.exe --register-shell
fastcopy.exe --unregister-shell
```

`--settings` 打开参数设置窗口。`--register-shell` / `--unregister-shell` 为当前用户注册或卸载右键菜单。

## 构建

需要 Rust stable、Visual Studio C++ Build Tools/Windows SDK；打包还需 7-Zip：

```powershell
cargo test
cargo build --release
node pack.js
```

可执行文件位于 `target/release/fastcopy.exe`。`node pack.js` 会编译 Release 并生成 `release/fastcopy_1.0.1.7z`（版本号来自 `Cargo.toml`）。Release 构建使用 OpenGL（glow）、LTO 和符号剥离以控制体积。

## 性能说明

- 大量小文件主要受磁盘随机读写、杀毒扫描和文件系统元数据操作限制，适当增加并发数通常有效。
- 复制对小文件使用 Windows `CopyFileEx` 并发。大于等于 64 MiB 的文件单独用 1 个线程，并尝试 `COPY_FILE_NO_BUFFERING`（不被支持时回退）。
- 机械硬盘不宜设置过高并发，建议 2–4；SSD/NVMe 可从默认值开始测试。
- 单个大文件的速度通常接近系统缓存和存储设备上限，不保证快于资源管理器。
- 回收站操作由 Windows Shell 完成，进度会在每个顶层项目完成后更新。

## 当前限制

- 首版仅支持 Windows 10/11 x64。
- ignore 文件仅在复制文件夹时生效，复制单个文件或移动/删除时不使用。
- 硬链接/符号链接/目录联接默认忽略；跟随则复制目标内容；保留则重建链接（目录联接会建成 junction；创建符号链接可能需要开发人员模式）。
- 文件校验目前校验长度，不计算内容哈希。
- 不复制 NTFS ACL 和备用数据流。目标卷不支持稀疏文件时会写成普通文件。
- 正在使用或共享锁定的文件会自动跳过，出现在结束时的失败列表中，可重试。其他权限或安全软件导致的失败也在同一列表中。
